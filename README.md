# 🔧 Measurement Converter (C++)

A menu-driven **Measurement Converter** developed using C++. This project allows users to convert different units of measurement, energy and power, and temperature through a simple command-line interface.

The project was created to practice C++ programming fundamentals and Object-Oriented Programming (OOP) concepts.

## 📌 Features

### 1. Measurement Conversions
- Millimeters (mm) to Centimeters (cm)
- Kilometers (km) to Meters (m)
- Kilograms (kg) to Grams (g)
- Liters (L) to Milliliters (mL)
- Centimeters (cm) to Millimeters (mm)
- Miles (mi) to Kilometers (km)
- Feet (ft) to Inches (in)
- Pounds (lb) to Grams (g)
- Acres to Square Feet
- Quintals to Kilograms (kg)

### 2. Energy & Power Conversions
- Watts (W) to Kilowatts (kW)
- Kilowatts (kW) to Watts (W)
- Horsepower (hp) to Kilowatts (kW)
- Kilowatts (kW) to Horsepower (hp)
- Megawatts (MW) to Kilowatts (kW)

### 3. Temperature Conversions
- Celsius (°C) to Fahrenheit (°F)
- Fahrenheit (°F) to Celsius (°C)
- Celsius (°C) to Kelvin (K)
- Fahrenheit (°F) to Kelvin (K)
- Kelvin (K) to Fahrenheit (°F)

## 📚 C++ Concepts Used

This project implements the following C++ programming concepts:

- **Object-Oriented Programming (OOP):** Organizing the program into separate classes.
- **Classes and Objects:** Creating classes for different conversion categories.
- **Encapsulation:** Using private and public access specifiers to manage data.
- **Member Functions:** Defining functions inside classes to perform conversions.
- **Switch-Case Statements:** Handling different conversion options.
- **While Loops:** Repeating conversion operations until the user exits.
- **Conditional Statements:** Using if conditions to control program execution.
- **Boolean Variables:** Managing loop execution through true and false values.
- **User Input and Output:** Using `cin` and `cout` to interact with users.
- **Arithmetic Operations:** Performing mathematical calculations using conversion formulas.
- **Control Statements:** Using `break` to control switch-case execution.
